# 光鸭云盘 · 设计预览稿

**对齐真实在跑的应用**：以 `ui/`（Ant Design Vue）实际样式为真值，而非另起炉灶。纯静态 HTML/CSS，无需构建。

## 打开方式

直接用浏览器打开 `design/index.html`（或双击）。无任何依赖、无需 `pnpm install`、不影响现有 Vue 代码。

- `index.html` — 入口导航页（6 个主页面卡片，目前只有「云盘文件」已完成）
- `app.html` — **当前方向**：云盘文件页，忠实复刻真实应用的侧栏 + 顶栏 + 文件表格。右上角状态切换条：
  - **已登录 / 空目录 / 加载中 / 未登录** 四套状态
  - 叠加开关：上传进度条、多选提示、文件右键菜单
- `app.css` — 设计系统：Tokens 直接对齐 `ui/theme.js` + `ui/styles.css` + 全部组件样式
- `cloud.html` / `glass.css` — 早期「液态玻璃」探索稿，**已弃用方向**，仅留档

## 设计真值（来自真实应用）

- **框架气质**：Ant Design Vue 轻量后台，紧凑、克制，不是液态玻璃。
- **强调色**：Ant 蓝 `#1677ff`（`theme.js: colorPrimary`）。
- **底色**：`#f5f7fb` 应用底 + 纯白侧栏/卡片，靠极淡阴影分层。
- **语义色**：成功 `#16a672` · 警告 `#f59e0b` · 危险 `#e5484d`。
- **尺寸**：`fontSize 13` · `controlHeight 28` · 圆角 `6/8`（均取自 `theme.js`）。
- **字体**：`Inter, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei'`。
- **画布**：主 `1040×760`，最小 `860×620`。

## 在真实基础上做的“调整”

`app.css` 中凡标注 `/* 调整 */` 的地方，是在忠实还原之上做的克制优化，未改变整体气质：

- 统一到 4px 间距栅格，替换散落魔法数。
- 阴影补一层极淡近距投影，增加纸感层次。
- 数字列启用等宽数字（`tabular-nums`），大小/时间不跳动。
- 补全键盘可见焦点环（真实应用缺失）与 `prefers-reduced-motion` 支持。
